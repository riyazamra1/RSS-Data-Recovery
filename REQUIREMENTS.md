# RSS Data Recovery Requirements

Requirements:
- Real device/data recovery functionality; do not simulate successful recovery.
- Free/Premium model.
- Image recovery must remain available to Free users.
- Registration first; RSS Core account/verification standard.
- Flow: splash -> registration -> welcome -> feature introduction -> main app.
- Recovery destination/folder: RSS Database Recovery.
- Biometric auto-unlock when enabled.
- Approved UI direction: centered cards/logo; clear app-lock unlock state; subtle glass effects; functional Light/Dark/System appearance.
- Build/test and verify actual recovery paths before completion.
